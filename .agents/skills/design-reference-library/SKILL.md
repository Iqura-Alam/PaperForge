# Design Reference Library

The reviewed reference library is stored at:

`E:\Study\Battery Low Interactive\PaperForge\.codex-local\sources\awesome-design-md\design-md`

Use it as inspiration and design-system evidence, not as permission to copy
brand assets, trademarks, or protected content.

1. Clarify the product, audience, surface, and desired tone when they are not
   already clear.
2. List candidate references with `rg --files` rather than loading the whole
   library into context.
3. Read only the two or three closest candidates. Compare their typography,
   palette, spacing, layout, motion, component treatment, and accessibility.
4. Recommend one reference or a clearly justified blend. Preserve the user's
   explicit brand and product requirements over the reference.
5. Copy a selected `DESIGN.md` to the project root only when the user asks to
   adopt it. Adapt it to the user's product instead of retaining stale names,
   claims, URLs, or assets from the reference brand.
6. When Impeccable or frontend-design also applies, use this library to ground
   the visual direction, then follow the more specific build or audit workflow.
